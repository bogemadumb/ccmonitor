# CCMonitor

Мои лимиты Claude Code прямо в строке меню macOS.

Мне надоело гадать, сколько осталось от лимита. Официально это нормально нигде не видно — либо упираешься в стенку без предупреждения, либо лезешь куда-то проверять вручную. Поэтому я повесил цифры прямо в menu bar: сколько сожрал от 5-часового окна, сколько времени до сброса и сколько токенов ушло. Клик по значку — раскрывается панель с деталями: оба лимита, 5 часов и 7 дней, с барами, разбивка токенов (ввод / вывод / кэш) и прикидка стоимости для справки.

Штука показывает лимиты **того, у кого она установлена**. Если поставите себе — увидите свои: она берёт OAuth-токен Claude Code из вашей связки ключей (Keychain) и логи ваших сессий из `~/.claude/projects`. Наружу ничего не уходит, кроме одного запроса к API Anthropic за вашими же лимитами.

## Скриншот

В самой строке меню это компактный значок вроде `◑ 47% · 2:14` — циферблат, процент 5-часового лимита и время до сброса. Кликаешь — вылезает панель с барами лимитов 5 ч / 7 дней и разбивкой токенов за сессию.

Панель приложение снимает само (в кадре — ваши собственные лимиты, так что кладите картинку в репозиторий на своё усмотрение):

```bash
mkdir -p docs
~/Applications/CCMonitor.app/Contents/MacOS/CCMonitor --snapshot docs/screenshot.png
```

## Возможности

- **Строка меню:** значок-«циферблат» (○ ◔ ◑ ◕ ●), процент 5-часового лимита и время до сброса (`◑ 47% · 2:14`). От 70 % желтеет в оранжевый, от 90 % краснеет.
- **Панель по клику:** оба лимита, 5 ч и 7 дней, с прогресс-барами и точным временем сброса.
- **Токены за сессию:** сумма по всем чатам внутри текущего 5-часового окна, разбитая на ввод / вывод / запись кэша / чтение кэша, плюс справочная цена в долларах.
- **Считает по-честному:** дедуп записей по `(message.id, requestId)`, чтобы не поймать дубли стриминг-плейсхолдеров; схлопывание sidechain-повторов; отдельный учёт `iterations` со своей моделью.
- **Окно берётся с сервера:** границы 5-часового окна тянутся из `resets_at` официального ответа о лимитах — поэтому число токенов совпадает с баром, а не плывёт. Если лимиты недоступны, окно восстанавливается по активности.
- **Не падает от сбоев:** ответ кэшируется на 2 минуты (endpoint жёстко rate-limited). Прилетел 429 или пропала сеть — показывает последнее известное значение с пометкой `*`, а отсчёт до сброса всё равно считается от абсолютного времени. Битый кэш просто игнорируется.
- **Автозапуск** при входе в систему через LaunchAgent.

## Как это работает

```
main.swift (AppKit, статусбар)  ──запускает──>  collector.py  ──> JSON в stdout
                                                     │
                                    ┌────────────────┴────────────────┐
                                    │                                 │
                         Keychain: OAuth-токен            ~/.claude/projects/*.jsonl
                         Claude Code                       (логи сессий)
                                    │                                 │
                                    v                                 v
                    api.anthropic.com/api/oauth/usage        подсчёт токенов
                    (лимиты 5 ч / 7 дней)
```

Всю логику данных я специально держу в Python — так её проще читать и править. Swift только дёргает скрипт раз в 30 секунд и рисует результат.

> **Важно:** endpoint `oauth/usage` — внутренний и недокументированный. Anthropic может изменить или убрать его в любой момент, и тогда лимиты перестанут показываться (токены из логов продолжат считаться). Ценник моделей в `PRICING` (`collector.py`) — справочный и зашит вручную: при подписке вы этих денег не платите, а при изменении цен таблицу нужно поправить руками.

## Стек

- **Swift + AppKit** — приложение в строке меню (`LSUIElement`, без иконки в доке), universal binary (arm64 + x86_64).
- **Python 3** — сбор данных, только стандартная библиотека, никаких зависимостей.
- **launchd** — автозапуск.

## Требования

1. **macOS 13 (Ventura) или новее**, Apple Silicon или Intel.
2. **Claude Code**, установленный и залогиненный, с подпиской Pro или Max. Без него данных не будет: приложение читает токен и логи именно оттуда.
3. **Xcode Command Line Tools** — нужны `swiftc` (сборка) и `python3`:
   ```bash
   xcode-select --install
   ```

Никаких API-ключей, токенов ботов и файлов `.env` заводить не нужно — приложение использует ваш собственный вход в Claude Code.

## Установка

```bash
git clone https://github.com/<ваш-аккаунт>/ccmonitor.git
cd ccmonitor
```

### 1. Сборка и установка приложения

```bash
bash build.sh
```

Скрипт компилирует Swift (universal, если доступен x86_64-таргет), собирает бандл `CCMonitor.app` с вложенным `collector.py` и ставит его в `~/Applications/`.

### 2. Автозапуск при входе в систему

`install.sh` ставит LaunchAgent, но ожидает собранное приложение рядом с собой, поэтому кладём его в папку репозитория на время установки:

```bash
cp -R ~/Applications/CCMonitor.app .
bash install.sh
rm -rf CCMonitor.app          # копия больше не нужна
```

Иконка появится в строке меню справа вверху. При первом обращении к паролю Claude Code macOS спросит доступ к связке ключей — нажмите **«Всегда разрешать»**, иначе диалог будет всплывать каждые 30 секунд.

> `CCMonitor.app` уже прописан в `.gitignore` — временная копия не попадёт в коммит.

### 3. Проверка

```bash
python3 collector.py --pretty
```

Должен вывести JSON с ключами `limits` и `tokens`. Если да — данные идут, и статусбар их покажет.

### Обновление

```bash
git pull && bash build.sh
launchctl kickstart -k "gui/$(id -u)/com.ccmonitor.app"
```

### Удаление

```bash
launchctl bootout "gui/$(id -u)/com.ccmonitor.app"
rm -rf ~/Applications/CCMonitor.app ~/Library/LaunchAgents/com.ccmonitor.app.plist
rm -rf ~/.claude/usage-monitor
```

## Структура

```
├── main.swift          Приложение в строке меню: опрос collector'а раз в 30 с,
│                       рендер заголовка и всплывающей панели (AppKit).
│                       Режим --snapshot <path> снимает панель в PNG без показа.
├── collector.py        Вся логика данных. Печатает JSON в stdout:
│                       лимиты из oauth/usage (с кэшем 120 с) + подсчёт токенов
│                       из JSONL-логов с дедупом. Флаг --pretty для чтения глазами.
├── test_collector.py   Дебаг-харнес: 12 сценариев сбоя и edge-case'ов.
│                       Главный инвариант — collector никогда не падает
│                       и всегда отдаёт валидный JSON. Запуск: python3 test_collector.py
├── build.sh            Компиляция Swift + сборка .app + установка в ~/Applications.
├── install.sh          Установка .app из релиза + LaunchAgent (автозапуск).
├── Info.plist          Манифест бандла (LSUIElement — приложение без иконки в доке).
└── AppIcon.icns        Иконка приложения.
```

Рантайм-данные вне репозитория: кэш лимитов лежит в `~/.claude/usage-monitor/limits-cache.json`.

## Тесты

```bash
python3 test_collector.py
```

Проверяются свежий и протухший кэш, 429, отсутствие сети, битый JSON, пустые логи, `<synthetic>`-записи, дедуп, `iterations`, границы окна и e2e-прогон подпроцессом. Ожидаемо: `Итог: 12/12 прошло`.

## Траблшутинг

| Что видно | Причина и что делать |
|---|---|
| В строке меню `CC …` | Collector не отдаёт данные. Запустите `python3 collector.py --pretty` и посмотрите поле `error`. |
| `CC ⚠︎` / «Токен истёк» | OAuth-токен протух. Откройте Claude Code и залогиньтесь — токен обновляется, когда Claude Code запущен. |
| «Лимиты обновляются…» | HTTP 429: endpoint строго rate-limited. Само пройдёт, опрос идёт не чаще раза в 2 минуты. |
| Звёздочка в `47%* · 2:14` | Показано последнее известное значение (сеть или 429), время до сброса при этом верное. |
| `error: no_token` | Claude Code не установлен, не залогинен, или вы запретили доступ к Keychain. Проверка: `security find-generic-password -s "Claude Code-credentials"`. |
| Постоянный запрос пароля | При диалоге Keychain нажмите «Всегда разрешать», а не «Разрешить». |
| «Не удаётся открыть: неустановленный разработчик» | Приложение не подписано. `xattr -dr com.apple.quarantine ~/Applications/CCMonitor.app`, затем Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно». |
| `swiftc: command not found` | `xcode-select --install`. |
| Иконки нет вообще | `launchctl list \| grep ccmonitor` — если пусто, повторите шаг 2. Логи: `log show --predicate 'process == "CCMonitor"' --last 5m`. |
| Токены есть, лимиты — нет | Вероятно, Anthropic изменила внутренний endpoint `oauth/usage`. |
| Пусто после обновления macOS | Пересоберите: `bash build.sh`. |
